# Hybi Branding

## Name
Hybi

## Tagline
Connect. Inspect. Replay.

## Description
Hybi is a real-time API client focused on asynchronous communication, especially WebSockets.

## Logo
A minimal geometric rocket centered inside a circular badge.

## Colors
- Primary circle: #10D1C5
- Text Color: #080D0D
- Rocket/symbol: #FFFFFF

## Brand attributes
- Technical
- Fast
- Real-time
- Clean
- Minimal
- Modern
- Developer-first

## Canonical asset

Los archivos de marca viven en `resources/images/`:

- `icon.svg` es la fuente editable del logo y lo que consume el renderer.
- `icon.png` (1024x1024) es la versión rasterizada; electron-builder deriva de
  ella los iconos nativos de Windows, macOS y Linux durante el empaquetado.

Si el logo cambia, se edita el SVG y se vuelve a exportar el PNG con el mismo
tamaño.

## Uso de la marca

El código se distribuye bajo GPL-3.0, pero el nombre «Hybi» y su logotipo no
forman parte de esa licencia. Una versión modificada y redistribuida debe usar
otro nombre y otro icono.
