# Código de conducta

## Nuestro compromiso

Quienes participamos en este proyecto nos comprometemos a que la experiencia sea
libre de acoso para todo el mundo, sin importar edad, tamaño corporal,
discapacidad, etnia, identidad o expresión de género, nivel de experiencia,
nacionalidad, apariencia, religión, orientación sexual o identidad afectiva.

## Comportamiento esperado

- Usar un lenguaje acogedor y respetuoso.
- Aceptar la crítica técnica con naturalidad: se critica el código, no a la
  persona.
- Explicar las decisiones y dar contexto en lugar de imponer.
- Priorizar lo mejor para el proyecto y para quienes lo usan.

## Comportamiento inaceptable

- Lenguaje o imágenes sexualizadas, y atención sexual no deseada.
- Insultos, ataques personales o políticos, y provocación deliberada.
- Acoso público o privado.
- Publicar información privada de terceros sin permiso.
- Cualquier conducta que resulte inapropiada en un entorno profesional.

## Aplicación

El mantenedor del proyecto es responsable de aclarar estas normas y puede
editar, borrar o rechazar comentarios, commits, código, issues y pull requests
que no se ajusten a ellas, así como bloquear de forma temporal o permanente a
quien las incumpla.

Los incidentes se reportan de forma privada a través de
[GitHub](https://github.com/joalvm). Todos los reportes se revisan y se
responden, y se respeta la confidencialidad de quien reporta.
